# 🏅 RunPlan

**RunPlan** é uma aplicação web React para planejamento inteligente de corrida, voltada para corredores iniciantes.

## Funcionalidades

- **⚡ Calculadora de Pace** – Descubra seu ritmo ideal com base no nível de condicionamento, idade e peso
- **📅 Plano de Treino** – Plano progressivo de 10% por semana até sua meta de distância
- **🏃 Modo Corrida** – Timer em tempo real com acompanhamento de pace e mensagens motivacionais
- **📊 Progresso** – Histórico de corridas com estatísticas (distância total, calorias, pace médio)

## Tecnologias

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/) para bundling
- [Tailwind CSS v4](https://tailwindcss.com/) para estilização
- [Vitest](https://vitest.dev/) para testes unitários

## Instalação e uso

```bash
npm install
npm run dev
```

| Comando | Descrição |

| `npm run dev` | Inicia o servidor de desenvolvimento |
| `npm run build` | Gera a build de produção |
